AgroLink Platform - Complete Technical Specification
1. PLATFORM OVERVIEW
Name: AgroLink Lagos
Purpose: Digital agricultural marketplace connecting farmers, buyers, and agro-processors across Nigeria
Program Tag: LAFSINCO/Produce for Lagos Registration
Target Market: Nigeria (Lagos food security initiative, expanding continent-wide)

User.is_farmer()        # role == 'farmer'
User.is_buyer()         # role == 'buyer'
User.is_admin()         # role == 'admin'
User.is_agro_processor() # role == 'buyer' AND buyer_type == 'agro_processor'
User.has_premium_access() # is_premium AND subscription active

6. PAYMENT & FEE STRUCTURE
6.1 Transaction Fees
Fee Type	Amount	Description
Platform Fee	1.5%	On all marketplace transactions
BOI Loan Processing	₦5,000	Non-refundable application fee
Premium Subscription	Variable	Monthly premium membership
Logistics Services	Variable	Delivery/pickup fees
6.2 Payment Flow
1. Transaction Initialization
   └── generate_reference() -> unique reference
   └── initialize_transaction() -> Paystack authorization URL
2. User Payment
   └── Redirect to Paystack payment page
   └── Card/Bank payment processing
3. Verification
   └── Callback to platform
   └── verify_transaction() -> status check
   └── Update database records
4. Logging
   └── PaymentLog entry created
   └── Transaction status updated

7.2 Dashboards

GET /marketplace - Browse produce
GET /produce/<id> - Produce details

POST /produce/<id>/edit - Edit listing

7.4 Processor Onboarding

7.5 BOI Loan Application
GET /processor/boi-loan/apply - Loan intro + fee info
POST /processor/boi-loan/payment - Initialize ₦5,000 payment
